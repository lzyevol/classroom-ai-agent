# L1 Mock 演示脚本

## 演示前声明

“本次展示验证的是成员 C 的 L1 浏览器端实现。回答、教材引用、课堂事件和练习评分均为固定 Mock，不代表真实 RAG、模型、数据库或认证已经联调完成。”

## 固定顺序

1. 首页展示三个核心入口。
2. QA 正常场景：提交“什么是具身智能？”，指出回答与引用分离，以及 `mock:` ID。
3. QA 无证据与 503：说明业务无命中不能伪装成依赖故障。
4. 课堂教师场景：展示增量文本、等待用户和 done 统计。
5. 课堂白板场景：展示 `wb_open`、`wb_draw_text` 和重复 actionId 未重复绘制。
6. 课堂断流或停止：展示 interrupted/cancelled 诊断。
7. 练习部分答错：完成三题，展示总分、逐题反馈和 Mock 引用。
8. 练习 422/409：展示题库不足与重复提交状态冲突。
9. 运行 Vitest 和 Playwright，展示测试数量与退出码。

## 不能声称

- “真实教材检索已经通过”
- “Agent 已完成多角色自主决策”
- “练习已持久化且并发安全”
- “认证和权限已经生效”
- “项目已经完整复现”
