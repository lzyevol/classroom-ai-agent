# 具身智能课程教学智能体任务进展

**更新时间：2026-08-05**
**当前状态：学生端、教师端、管理员端核心业务闭环已可联调；当前重点为体验优化、资源补齐、稳定性验证与部署交付。**

## 一、当前总体进度

项目已从“学生端单点学习工具”发展为覆盖学生学习、教师教学干预和管理员账号管理的三端教学平台。当前已具备：

- 教材知识图谱支撑的课程问答、章节学习、练习生成与智能批改；
- 学习记录、章节/小节掌握度、知识点诊断、错题复习与学习建议；
- 教师班级概览、学生详情、按小节查看班级掌握情况及作业全流程；
- 管理员用户管理、角色权限与账号生命周期控制；
- SQLite 演示数据、题库、课程资源及主要接口自动化测试。

## 二、学生端已完成功能

### 1. 登录、课程学习与智能问答

- 完成学生登录认证、角色识别与首页入口。
- 支持基于 Neo4j 教材知识图谱的多轮智能问答。
- 问答结果可返回教材原文、章节定位和相关图片，避免无依据回答。
- 完成智能课堂、课件播放、白板和多角色互动讨论。
- 支持浏览器语音、Edge TTS 和通义千问 TTS，并可在前端切换语音能力。
- 已支持课程目录、章节访问记录和预生成课件浏览。

### 2. 章节练习与错题闭环

- 支持学生按小节、题型、难度和题量发起自主章节练习。
- 支持选择题、判断题和简答题；提交后记录答案、得分、错因与教材依据。
- 支持智能批改、练习会话恢复、错题记录和后续复习。
- 首页“章节练习”入口不再因教师作业而强制跳转：学生始终可以进入自主练习。
- 若存在待完成教师作业，学生可在同一张章节练习卡片中展开任务列表，按作业标题、小节、题量、截止日期和进度选择具体任务。
- 待完成作业按“进行中优先、截止时间更近优先”展示；完成教师作业与自主练习的业务记录分离。

### 3. 学习中心与学习建议

- 学习中心已提供总体掌握度、章节/小节掌握度、知识点掌握度、错题本、最近练习和下一步建议。
- 首页已将“知识实体数量、知识关系数量”等系统技术指标替换为面向学生的“今日学习提醒”。
- 今日学习提醒展示待完成教师任务、待复习错题和推荐学习内容，并可进入学习中心查看建议。
- 当前产品交互方向明确为：**行动优先 → 小节掌握 → 错题处理 → 知识点/历史下钻**。

## 三、教师端已完成功能

### 1. 班级与学生学情

- 支持查看本人负责班级的概览、学生列表、筛选、分页和学生详情。
- 学生详情支持查看总体成绩、已学习章节、完成练习、错题数量、章节掌握度和知识点诊断。
- 新增班级“小节掌握情况”接口与页面：按小节聚合作答得分、参与学生数、作答次数和题库可用客观题数。
- 小节列表覆盖题库中可布置作业的小节；即使学生尚未练习，也可展示为“未练习”并支持直接布置作业。
- 知识点分析保留为学生详情中的下钻诊断，不再作为教师教学干预的主入口。

### 2. 教师作业与教学干预

- 支持教师按**章节/小节**创建面向全班的作业，设置标题、说明、题量和截止时间。
- 新作业默认覆盖所选小节的可用选择题和判断题；历史知识点专项作业数据仍兼容。
- 支持查看作业列表、完成率、任务得分、干预前后掌握度、平均变化、关闭和删除作业。
- 支持学生端获取任务、开始/恢复指定作业、提交后回写作业进度和小节掌握度变化。
- 已增加作业发布、开始、提交、关闭、删除、权限、题量校验和小节掌握情况的自动化测试。

## 四、管理员端已完成功能

- 支持用户新增、查询、修改、删除、分页和筛选。
- 支持重置密码、启用/停用账号。
- 支持学生、教师、管理员角色权限校验。
- 教师和管理员均受后端接口权限控制；教师只能访问本人负责班级的数据。

## 五、技术与数据实现现状

- **前端**：Next.js + React + TypeScript + Tailwind CSS，已实现学生、教师、管理员三端页面。
- **后端**：FastAPI，采用 API 路由层、服务层、Pydantic Schema 和 SQLite 数据访问的分层结构。
- **知识与课程资源**：Neo4j 用于知识图谱检索；SQLite 保存用户、班级、练习、作答、掌握度、错题与作业数据。
- **作业数据模型**：已落地 teaching_assignments、assignment_students 和 practice_sessions.assignment_id 等关联数据。
- **题库与练习**：题库支持按小节、题型、难度和知识点筛选；教师小节作业使用同一题库能力。
- **服务运行**：本地后端通过 Uvicorn 提供 API，前端通过 /backend/* 代理访问后端。

## 八、阶段总结

当前系统已经形成可演示的教学闭环：

> 教材学习与问答 → 自主/教师作业练习 → 智能批改与错题记录 → 小节掌握分析与学习建议 → 教师查看班级学情并布置下一轮作业。

后续工作将以学生学习决策体验、教师教学动作效率、课程资源覆盖和部署稳定性为重点，而非继续堆叠面向系统内部的技术指标。

## 九、学习中心最新交互修订（2026-08-05）

本次版本进一步将学习中心从“数据报表页”调整为“学生行动页”：

- 顶部只保留一个“下一步行动”，优先显示进行中的教师作业，其次显示截止时间更近的待完成作业，再考虑学习推荐。
- 顶部概览指标精简为总体掌握度、待复习错题和已学习小节，移除与总体掌握度重复的客观题正确率。
- 小节掌握度成为主视图，默认分为“需要优先复习”和“正在巩固”；完整小节列表通过展开区域查看。
- 知识点掌握度降级为“知识点诊断”折叠区域，作为小节薄弱原因的下钻信息。
- 错题本改为按章节/小节聚合，学生先看到每个小节有多少道待复习错题，再展开查看具体题目或进入集中复习。
- 最近练习保留为底部历史信息，不再与下一步行动、小节掌握和错题处理并列抢占主要注意力。
- “已学习小节”现在只显示实际学习小节数量，不再将“有掌握度数据的小节数量”误作为总数，避免出现类似 19 / 2 的错误比例。
