## 1. 当前阶段结论

项目已经从早期的“教材清洗与问答 MVP”进入多角色教学平台开发阶段。

目前学生端的主要学习闭环已经基本完成：

1. 登录系统并进入学生主页。
2. 按目录选择章节，进入智能课堂学习。
3. 在课堂中查看课件、白板内容并参与多角色互动讨论。
4. 使用浏览器语音、Edge TTS 或通义千问 TTS 播放讲课和讨论内容。
5. 针对课程内容进行多轮智能问答，并查看教材原文、章节位置和相关图片。
6. 完成预生成的章节练习，提交后获得智能批改、选项对照、错因分析和教材依据。
7. 在学习中心查看已学课程、知识点掌握度、错题和个性化学习建议。

教师和管理员的登录身份、基础权限以及班级访问关系已经接通，但正式工作台仍处于待开发状态。下一阶段优先开发管理员端用户管理，然后开发教师端学情与班级管理。

Docker 暂不处理。待主要业务功能开发完成、前后端构建稳定后，再统一完成容器化和部署交付。

## 3. 已完成的功能

### 3.1 教材数据处理与知识图谱

已完成《具身智能导论》PaddleOCR 数据的清洗、章节重建、文本分块、图片提取、知识实体与关系抽取。

主要成果：

- 140 个教材小节。
- 426 个可检索原文片段。
- 788 个知识实体。
- 338 条知识点关系。
- 1,143 条知识点与小节关系。
- 1,297 条知识点与原文证据关系。
- 434 张实际课程图片，另有 1 个目录占位文件；`images.jsonl` 中记录 434 项图片元数据。
- 完整知识图谱文件位于 `data/processed/knowledge_graph.json`。

Neo4j 数据结构：

```text
(KnowledgeEntity)-[:EVIDENCED_BY]->(Chunk)-[:BELONGS_TO]->(Section)
(KnowledgeEntity)-[:MENTIONED_IN]->(Section)
(KnowledgeEntity)-[:USES|PART_OF|DEPENDS_ON|...]->(KnowledgeEntity)
```

教材原文通过 `Chunk.quote_original` 返回，`Chunk.content_clean` 用于检索和模型上下文。页码、OCR 坐标等内部追溯字段不在学生端展示。

### 3.2 登录、账号与权限基础

已完成：

- 学生、教师、管理员三种角色登录。
- SQLite 登录会话和退出登录。
- 当前用户查询与路由身份校验。
- 学生只能访问本人学习数据。
- 教师只能查看负责班级及班级学生。
- 管理员可以读取系统用户和全部班级基础信息。
- 默认演示账号：`student`、`teacher`、`admin`。

当前尚未完成管理员对用户的新增、修改、删除、重置密码和启停账号。

### 3.3 智能问答

已完成：

- 基于 Neo4j 教材知识图谱与原文片段的问答。
- DeepSeek 生成回答，证据不足时明确提示。
- 多轮会话上下文和省略式追问主题继承，例如先问“具身智能是什么”，再问“详细介绍一下”。
- 教材原文、章/节/小节位置和相关图片展示。
- 清理原文标题中的 Markdown `####` 等异常展示标记。
- 数学公式渲染，避免直接显示 `$...$` 符号。
- 大图支持更清晰的显示和查看，降低固定窄宽导致的文字不可读问题。
- 问答内容语音播放和语音引擎选择。

### 3.4 智能课堂与课件

已完成：

- 章节目录选择页和目录预加载优化。
- 课堂返回到章节选择页，不再直接跳回主页。
- 复用 OpenMAIC 课堂运行时，而不是另写简化课堂。
- 课件舞台、白板、讲课流程和课堂互动讨论。
- 讨论前可配置语言模型。
- 课堂讨论按照“当前角色语音播放完成后，再生成或播放下一位角色”的顺序推进，避免文字对话结束后语音仍长时间排队。
- 清理讨论模型返回中的 `{"type":"text","content":"..."}` 包装，避免 JSON 原样显示到气泡中。
- 讲课与讨论均接入语音播放。
- 不同讨论角色可自动分配不同声音。
- 课堂进行中可临时切换语音模型或音色。
- 主页设置与课堂设置已统一为同一套设置组件和状态。
- 设置中会显示当前使用的模型、语音引擎和音色，并提供选中状态。
- 浏览器内置语音、Edge TTS 和通义千问 TTS 均可选择。

已预生成并保存在 SQLite 中的课件共 15 节：

- 第 1 章：1.1—1.7，共 7 节。
- 第 2 章：2.1—2.8，共 8 节。

这些课件无需每次上课重新生成。第 3—13 章课件尚未批量生成。

### 3.5 章节练习与智能批改

已完成：

- 按章节开始练习。
- 优先使用 SQLite 中预生成的题库，不需要每次请求模型临时出题。
- 支持选择题、判断题和简答题。
- 提交整套练习并生成成绩。
- 客观题自动判分，主观题使用模型辅助批改。
- 批改结果同时显示题目原选项、学生选择、正确答案、解析和教材依据。
- 错题自动进入学习中心。
- 练习会话与当前登录学生绑定，避免不同用户数据混用。

当前题库包含 150 道预生成题，数据库中保留 21 次练习、44 道练习题实例和 43 条答题/批改记录。

### 3.6 学习记录、掌握度与推荐

已完成：

- 进入课程小节时记录学习访问，不统计不可靠的“学习分钟数”。
- 展示学生学过哪些课程和最近学习时间。
- 根据练习结果计算知识点掌握度。
- 展示待复习错题和个性化学习建议。
- 学习记录、知识点掌握度和错题本采用固定区域与分页展示，避免数据增多后页面无限拉长。
- 知识点掌握度支持按章节筛选。
- 错题本支持按章节筛选。
- 可从掌握度或错题进入知识点复习详情，查看教材解释与原文。
- 二级页面返回按钮的图标、文字和位置已统一。

当前 SQLite 中保留 6 条课程学习记录，供演示学习中心使用。

### 3.7 语音能力

系统目前支持三类语音：

| 语音方式 | 是否需要 API Key | 说明 |
| --- | --- | --- |
| 浏览器内置语音 | 否 | 依赖当前电脑、操作系统与浏览器提供的音色 |
| Edge TTS | 否 | 由后端生成微软 Neural 语音，中文自然度较高 |
| 通义千问 TTS | 是 | 需要配置 `QWEN_TTS_API_KEY` |

语音设置支持：

- 在统一设置中选择语音引擎和具体音色。
- 显示当前选中的语音方式。
- 讲课、问答和课堂讨论共用配置。
- 课堂进行中临时切换。
- 讨论角色使用不同音色。

浏览器语音的具体音色不会随 Git 仓库迁移，新电脑需要重新选择。

## 9. 启动与交接说明

完整启动命令见根目录 `README.md`。新电脑运行时需要特别注意：

1. 根目录 `.env` 不会提交到 Git，需要从 `.env.example` 复制并重新填写 Neo4j 密码和模型密钥。
2. `data/classroom.db`、`data/processed/` 和 `data/images/` 已提交，不需要重新生成当前演示数据。
3. Neo4j 本地数据库本身不会随 Git 迁移，需要执行 `scripts/10_import_neo4j.py`。
4. 浏览器本地保存的模型和语音选择不会随 Git 迁移，需要在设置中重新选择。
5. 提交更新后的 SQLite 数据前应先停止后端，使 WAL 内容合并进 `data/classroom.db`。
6. 不要提交 `.env`、`data/classroom.db-wal`、`data/classroom.db-shm` 或 `data/local-backups/`。
